# Sistema de Gestión y Consolidación de Actividades Institucionales

Sistema orientado a apoyar la gestión, organización, seguimiento y consolidación de información relacionada con las actividades institucionales de la **Bluefields Indian & Caribbean University (BICU)**.

El proyecto surge a partir de la necesidad de facilitar el manejo de información generada durante la planificación y ejecución de actividades universitarias, especialmente aquella relacionada con participantes, evidencias, informes y consolidación de resultados.

## Propósito

El sistema busca proporcionar una forma organizada y trazable de gestionar la información institucional generada durante las actividades desarrolladas por la universidad.

Su propósito principal es reducir el trabajo manual asociado con la recopilación, revisión, organización y consolidación de información, manteniendo como prioridad la integridad de los datos y la trazabilidad de los procesos.

## Utilidad para la BICU

La gestión de actividades institucionales puede involucrar diferentes fuentes de información, documentos, listas de participantes, evidencias y reportes.

Este proyecto busca centralizar y organizar ese proceso para facilitar tareas como:

* Registro y seguimiento de actividades.
* Organización de información de participantes.
* Gestión de evidencias asociadas a las actividades.
* Identificación de inconsistencias que requieren revisión.
* Organización de información para los diferentes reportes institucionales.
* Consolidación periódica de resultados.
* Conservación de la trazabilidad de la información.
* Reducción de tareas repetitivas de procesamiento manual.

De esta manera, el sistema está pensado como una herramienta de apoyo para fortalecer la gestión de información institucional y facilitar la preparación de los productos requeridos por los procesos universitarios.

## Alcance

El proyecto contempla el ciclo de información asociado a una actividad institucional:

**Planificación → Ejecución → Participantes → Evidencias → Revisión → Consolidación → Reportes**

La información generada durante cada etapa puede mantenerse relacionada para facilitar su posterior consulta, revisión y consolidación.

## Principios del proyecto

El desarrollo del sistema se orienta por los siguientes principios:

### Integridad de la información

Los datos registrados deben conservar su significado y procedencia. El sistema evita realizar modificaciones silenciosas que puedan alterar la información original.

### Trazabilidad

Las operaciones relevantes deben poder relacionarse con la información que las originó, facilitando la revisión posterior.

### Revisión antes que corrección

Cuando se identifica una inconsistencia, el sistema prioriza señalarla para su revisión antes que modificar automáticamente la información.

### Organización institucional

La información se estructura de acuerdo con las necesidades del proceso institucional, procurando mantener una separación clara entre los datos registrados y los documentos generados.

### Evolución controlada

El proyecto se desarrolla progresivamente, validando cada etapa antes de incorporar nuevas funcionalidades.

## Beneficiarios

El sistema está orientado principalmente a apoyar a las áreas universitarias responsables de planificar, ejecutar, documentar, revisar y consolidar actividades institucionales.

Su utilización puede contribuir a:

* Mejorar la organización de la información.
* Reducir procesos manuales repetitivos.
* Facilitar la revisión de datos.
* Mejorar la disponibilidad de información histórica.
* Agilizar la preparación de reportes.
* Fortalecer la trazabilidad de las actividades realizadas.

## Contexto institucional

El proyecto toma como referencia procesos reales relacionados con la gestión de actividades universitarias de la **BICU**, particularmente aquellos que requieren documentar la planificación, ejecución, participantes, evidencias y resultados de las actividades desarrolladas.

El sistema se encuentra en desarrollo y su evolución está siendo realizada de manera progresiva, tomando como referencia las necesidades identificadas durante el análisis del proceso institucional.

**En desarrollo activo.**

* Cambios controlados.
* Validación progresiva.
* Conservación de la información.
* Trazabilidad de operaciones.
* Separación de responsabilidades.

## Proyección

* Gestión de actividades.
* Participantes.
* Evidencias.
* Revisión y validación de información.
